# 05 — SEO Guide

## Built-in SEO features

All handled in `src/layouts/BaseLayout.astro`:

- **Unique title & description** per page via props.
- **Canonical URL** for every page.
- **Robots meta:** `index, follow, max-image-preview:large`.
- **Open Graph tags:** `og:type`, `og:site_name`, `og:title`, `og:description`, `og:url`, `og:image`.
- **Twitter card tags.**
- **JSON-LD structured data** (`Organization` schema).
- **RSS alternate link.**
- **Favicon and theme color.**

## Sitemap

Generated by `@astrojs/sitemap`. After build:

- `sitemap-index.xml` → main sitemap index
- `sitemap-0.xml` → actual page URLs

**Submit to Google Search Console:**
`https://animezenith.github.io/sitemap-index.xml`

## RSS feed

Generated at `/rss.xml` from `src/pages/rss.xml.js`. Uses `@astrojs/rss`.

## robots.txt

Located at `public/robots.txt`. Controls crawler access. Should allow all and reference the sitemap.

## SEO best practices for new content

1. **Unique titles:** Every post title should be distinct.
2. **Descriptive excerpts:** 120–160 characters, includes target keywords.
3. **Slug quality:** Short, hyphenated, keyword-rich (`best-new-anime-to-watch`, not `post-1`).
4. **Alt text for images:** If you add `<img>`, include alt attributes.
5. **Internal linking:** Link related articles to each other.
6. **Update dates:** Keep `date` fields accurate.
7. **Image sizes:** Use optimized images (Unsplash auto-sizes via URL params).
8. **Canonical:** Never duplicate content across slugs.

## What NOT to worry about

- Keyword-stuffed domains (they don't help much anymore).
- Meta keywords tag (Google ignores it).
